# Fase 1 — MVP da palestra: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** registrare un allenamento completo in palestra, anche offline: libreria esercizi, programmi con giornate, schermata Oggi, modalità allenamento con precompilazione e timer di recupero, riepilogo, impostazioni e backup.

**Architecture:** tutto è locale. Dexie (IndexedDB) contiene i dati.
- `src/db/` è l'unico punto di accesso alle tabelle. Ogni modulo espone funzioni asincrone e i componenti le leggono con `useLiveQuery`, quindi ogni scrittura aggiorna subito l'interfaccia.
- Le regole di calcolo sono funzioni pure in `src/domain/`, ognuna con i suoi test.
- I componenti React sono in `src/features/<area>/`, le primitive dell'interfaccia in `src/components/` e le API del browser in `src/platform/`.

**Tech Stack:** React 19, React Router 8 (data mode), Dexie 4.4 con dexie-react-hooks, Zod 4, lucide-react 1.x, Tailwind 4.3, Vitest 5 con fake-indexeddb.

**Spec:** `docs/SPEC.md` (§4–§9, §11, §13). Prerequisito: Fase 0 completata (`2026-10-02-fase-0-scaffold.md`), che contiene anche il sistema visivo, nel Task 2.

Note di compatibilità verificate:

- Dexie: si usa `Table<T, string>` e non `EntityTable`, così il compilatore richiede l'`id` in `add()` (gli ID li genera l'app).
- Zod 4: `import { z } from 'zod'`. `z.object` scarta le chiavi sconosciute. `z.record` vuole due argomenti.
- lucide-react 1.x: le icone hanno `aria-hidden` per default; i pulsanti che contengono solo un'icona hanno bisogno di `aria-label`.
- fake-indexeddb funziona con Vitest in ambiente `node`. Niente jsdom.

## Global Constraints

- **Dati.** Il database si usa solo da `src/db/`; i componenti non toccano le tabelle Dexie. I calcoli di dominio (e1RM, volume, rotazione, precompilazione, settimane) sono funzioni pure in `src/domain/`, con test.
- **Formati.**
  - Timestamp in epoch ms; date di calendario `YYYY-MM-DD`; pesi in kg; ID con `crypto.randomUUID()`.
  - Numeri con `Intl.NumberFormat('it-IT')`. L'input del peso accetta "82,5" e "82.5".
  - Nei riepiloghi le serie si separano con " / " (`80×10 / 80×9 / 77,5×8`).
- **Storico.**
  - Lo storico non si perde mai. Esercizi e programmi già usati si archiviano (`archivedAt`), non si cancellano.
  - Le sessioni sono snapshot: modificare un programma non cambia le sessioni passate.
- **Schema.** Dexie versione 1 come in SPEC §4.1. Non modificare mai una versione esistente. Niente indici su booleani o su valori `undefined`. Il programma attivo sta in `settings.activeProgramId`.
- **Allenamento.**
  - Ogni modifica si scrive subito in IndexedDB. Dopo una chiusura forzata si riprende dalla stessa serie.
  - Ogni timer si calcola da un `endAt` salvato e si ricalcola a ogni `visibilitychange`; mai decrementare un contatore.
  - Il Wake Lock si riacquisisce a ogni ritorno in primo piano.
  - Mai ricaricare l'app durante un allenamento: l'avviso di aggiornamento è nascosto in modalità allenamento e quando c'è una sessione in corso.
- **Browser.**
  - Niente `localStorage` né `sessionStorage` per i dati dell'app. Niente `navigator.vibrate`.
  - Input con font di almeno 16px. `inputmode="decimal"` per i pesi, `"numeric"` per ripetizioni e secondi.
- **Interfaccia.**
  - Testi in italiano secondo SPEC §11.4: sola iniziale maiuscola, verbi attivi, stessa azione con lo stesso nome in tutto il flusso. Gli errori indicano la soluzione e gli stati vuoti invitano ad agire.
  - Codice, commenti e commit in inglese, con Conventional Commits.
  - Target touch di almeno 44pt, 56pt in modalità allenamento. Movimento solo in risposta a un'azione, con `prefers-reduced-motion` rispettato.
  - Ogni colore dei dischi ha un solo significato: blu azione primaria e serie corrente, verde completato e recupero finito, giallo record (Fase 2), rosso azioni distruttive (solo l'icona, vedi Fase 0, Task 2).
- **Dipendenze.** Nessuna oltre a quelle dello stack in `CLAUDE.md`.
- **Fine di un task.** Un task è completo quando `bun run check` passa. Dopo ogni modifica lancia `bun run format`.

## Deviazioni dalla spec, decise in questo piano

1. **`ActiveTimer.durationMs`.** `activeTimer` riceve anche questo campo, la durata totale compresi i "+15 s", che serve alla linea che si svuota. È il valore di un'impostazione, non lo schema Dexie, quindi nessuna migrazione.
2. **Durata predefinita.** Per gli esercizi a durata (`targetSec`) è di 30 s: la spec non la fissa.
3. **Peso degli esercizi a corpo libero.** Per un esercizio `bodyweight_reps` senza storico il peso vale 0 ("0 = corpo libero", SPEC §4) invece di restare vuoto: basta inserire le ripetizioni.
4. **"Avvia recupero".** Nella barra del timer, quando non c'è un recupero attivo, il pulsante avvia il recupero a mano. Senza, con `autoStartTimer` disattivato il timer non partirebbe mai.
5. **Editor della serie corrente.** Gli stepper compaiono solo sulla serie selezionata (di default la corrente), espansa su più righe. Le altre serie sono righe compatte con valori e disco di stato. A 375pt di larghezza due stepper e il pulsante di conferma non stanno su una riga con target da 56pt (vedi Task 16).
6. **Conferme.** Le conferme distruttive usano `window.confirm` nativo. Solo la scelta "Termina" o "Scarta" per una sessione vecchia usa un foglio, perché ha due azioni.

```ts
import Dexie, { type Table } from 'dexie';
import type {
  Bodyweight,
  Day,
  DayExercise,
  Exercise,
  Program,
  Session,
  SessionExercise,
  Setting,
  SetLog,
} from '../types';

export const db = new Dexie('gym-log') as Dexie & {
  exercises: Table<Exercise, string>;
  programs: Table<Program, string>;
  days: Table<Day, string>;
  dayExercises: Table<DayExercise, string>;
  sessions: Table<Session, string>;
  sessionExercises: Table<SessionExercise, string>;
  setLogs: Table<SetLog, string>;
  bodyweights: Table<Bodyweight, string>;
  settings: Table<Setting, string>;
};

// Never edit an existing version. Schema changes go in db.version(n + 1) with an upgrade(),
// together with a migration of the backup format (src/db/backup.ts).
db.version(1).stores({
  exercises: 'id, name, muscleGroup',
  programs: 'id',
  days: 'id, programId',
  dayExercises: 'id, dayId, exerciseId',
  sessions: 'id, status, startedAt, programId, dayId',
  sessionExercises: 'id, sessionId, exerciseId',
  // Planned sets have no completedAt, so the compound index only sees performed sets.
  setLogs: 'id, sessionId, sessionExerciseId, [exerciseId+completedAt]',
  bodyweights: 'id, date',
  settings: 'key',
});

export const uid = (): string => crypto.randomUUID();
```

```ts
import { db } from './db';

export const DEFAULT_SETTINGS: Settings = {
  activeProgramId: null,
  weeklyGoal: 3,
  defaultRestSec: 90,
  autoStartTimer: true,
  timerSound: true,
  weightSteps: { barbell: 2.5, dumbbell: 2, machine: 5, cable: 2.5, bodyweight: 2.5, other: 2.5 },
  activeTimer: null,
  pushEnabled: false,
  lastBackupAt: null,
  seedVersion: 0,
};

export async function getSettings(): Promise<Settings> {
  const rows = await db.settings.toArray();
  return { ...DEFAULT_SETTINGS, ...Object.fromEntries(rows.map((r) => [r.key, r.value])) } as Settings;
}

export async function setSetting<K extends keyof Settings>(key: K, value: Settings[K]): Promise<void> {
  await db.settings.put({ key, value });
}
```

```ts
  const d = new Date(ts);
```

```ts
import type { SetLog, TrackingType } from '../types';
import { DAY_MS } from './dates';

export type SetValues = Pick<SetLog, 'weightKg' | 'reps' | 'durationSec'>;

export interface Target {
  sets: number;
  repMin: number;
  repMax: number;
  targetSec?: number;
  restSec: number;
}

const number = new Intl.NumberFormat('it-IT', { maximumFractionDigits: 2 });
const megabytes = new Intl.NumberFormat('it-IT', {
  style: 'unit',
  unit: 'megabyte',
  maximumFractionDigits: 1,
});
const relative = new Intl.RelativeTimeFormat('it', { numeric: 'auto' });
const longDate = new Intl.DateTimeFormat('it-IT', { weekday: 'long', day: 'numeric', month: 'long' });
const timeOfDay = new Intl.DateTimeFormat('it-IT', { hour: '2-digit', minute: '2-digit' });

export const formatNumber = (n: number): string => number.format(n);
export const formatMegabytes = (bytes: number): string => megabytes.format(bytes / 1_000_000);
export const formatDate = (ts: number): string => longDate.format(ts);
export const formatTime = (ts: number): string => timeOfDay.format(ts);

/** "82,5", "82.5" and " 82 " are valid; negatives, "1e3" or "82 kg" give undefined. */
export function parseWeight(input: string): number | undefined {
  const text = input.trim();
  return /^\d+(?:[.,]\d+)?$/.test(text) ? Number(text.replace(',', '.')) : undefined;
}

export function parseInteger(input: string): number | undefined {
  const text = input.trim();
  return /^\d+$/.test(text) ? Number(text) : undefined;
}

export const countLabel = (n: number, one: string, many: string): string =>
  `${number.format(n)} ${n === 1 ? one : many}`;

export function formatSeconds(sec: number): string {
  if (sec < 60) return `${sec} s`;
  const min = Math.floor(sec / 60);
  return sec % 60 ? `${min} min ${sec % 60} s` : `${min} min`;
}

/** 102_000 → "1:42", 3_723_000 → "1:02:03". */
export function formatClock(ms: number): string {
  const total = Math.floor(Math.max(0, ms) / 1000);
  const h = Math.floor(total / 3600);
  const m = Math.floor((total % 3600) / 60);
  const s = String(total % 60).padStart(2, '0');
  return h > 0 ? `${h}:${String(m).padStart(2, '0')}:${s}` : `${m}:${s}`;
}

export const formatRange = (min: number, max: number): string =>
  min === max ? `${min}` : `${min}–${max}`;

export function formatSet(set: SetValues, tracking: TrackingType): string {
  if (tracking === 'duration') return formatSeconds(set.durationSec ?? 0);
  const reps = set.reps ?? 0;
  if (tracking === 'bodyweight_reps') {
    return set.weightKg ? `+${number.format(set.weightKg)}×${reps}` : `${reps}`;
  }
  return `${number.format(set.weightKg ?? 0)}×${reps}`;
}

export const formatSets = (sets: SetValues[], tracking: TrackingType): string =>
  sets.map((s) => formatSet(s, tracking)).join(' / ');

const each = (t: Target, tracking: TrackingType) =>
  tracking === 'duration' ? formatSeconds(t.targetSec ?? 0) : formatRange(t.repMin, t.repMax);

/** "4 serie da 8–12, recupero 2 min" */
export const formatTarget = (t: Target, tracking: TrackingType): string =>
  `${t.sets} serie da ${each(t, tracking)}, recupero ${formatSeconds(t.restSec)}`;

/** "4 × 8–12": sets × reps, as listed on the Today screen. */
export const formatSetsReps = (t: Target, tracking: TrackingType): string =>
  `${t.sets} × ${each(t, tracking)}`;

/** "4 × 8–12, 2 min" for the day editor rows. */
export const formatShortTarget = (t: Target, tracking: TrackingType): string =>
  `${formatSetsReps(t, tracking)}, ${formatSeconds(t.restSec)}`;

const startOfDay = (ts: number) => new Date(ts).setHours(0, 0, 0, 0);

/** "oggi", "ieri", "4 giorni fa": calendar days in local time. */
export function relativeDay(ts: number, now = Date.now()): string {
  return relative.format(-Math.round((startOfDay(now) - startOfDay(ts)) / DAY_MS), 'day');
}
```

```ts
import type { SetLog, TrackingType } from '../types';
import type { SetValues } from './format';

export type LoggedSet = SetValues & Pick<SetLog, 'isWarmup' | 'completedAt'>;

/** Epley (SPEC §8.2): a single is the weight itself; not computed above 12 reps. */
export function e1rm(weightKg: number, reps: number): number | undefined {
  if (weightKg <= 0 || reps < 1 || reps > 12) return undefined;
  return reps === 1 ? weightKg : weightKg * (1 + reps / 30);
}

export const isWorkSetDone = (s: LoggedSet): boolean => s.completedAt !== undefined && !s.isWarmup;

/** Tonnage of completed work sets; bodyweight and duration exercises have none. */
export function volume(sets: LoggedSet[], tracking: TrackingType): number {
  if (tracking !== 'weight_reps') return 0;
  return sets.filter(isWorkSetDone).reduce((sum, s) => sum + (s.weightKg ?? 0) * (s.reps ?? 0), 0);
}

function score(s: LoggedSet, tracking: TrackingType): [number, number] {
  if (tracking === 'duration') return [s.durationSec ?? 0, 0];
  if (tracking === 'bodyweight_reps') return [s.reps ?? 0, s.weightKg ?? 0];
  const weight = s.weightKg ?? 0;
  return [e1rm(weight, s.reps ?? 0) ?? weight, s.reps ?? 0];
}

/** Highest e1RM (weighted), most reps (bodyweight), longest hold (duration). */
export function bestSet<T extends LoggedSet>(sets: T[], tracking: TrackingType): T | undefined {
  let best: T | undefined;
  for (const s of sets.filter(isWorkSetDone)) {
    if (!best) {
      best = s;
      continue;
    }
    const [a1, a2] = score(s, tracking);
    const [b1, b2] = score(best, tracking);
    if (a1 > b1 || (a1 === b1 && a2 > b2)) best = s;
  }
  return best;
}

export function summarize(exercises: { trackingType: TrackingType; sets: LoggedSet[] }[]): {
  sets: number;
  volume: number;
} {
  return {
    sets: exercises.reduce((n, e) => n + e.sets.filter(isWorkSetDone).length, 0),
    volume: exercises.reduce((v, e) => v + volume(e.sets, e.trackingType), 0),
  };
}
```

```ts
export function prefill(last: SetValues[], count: number): SetValues[] {
  return Array.from({ length: count }, (_, i) => {
    const s = last[Math.min(i, last.length - 1)];
    return s ? { weightKg: s.weightKg, reps: s.reps, durationSec: s.durationSec } : {};

type PlannedSet = Pick<SetLog, 'id' | 'index' | 'isWarmup' | 'weightKg' | 'completedAt'>;

/** SPEC §6.3: ids of later uncompleted work sets that still have the changed set's old weight. */
export function propagateWeight(sets: PlannedSet[], changedId: string): string[] {
  const changed = sets.find((s) => s.id === changedId);
  if (!changed || changed.isWarmup || changed.completedAt !== undefined) return [];
  return sets
    .filter(
      (s) =>
        s.index > changed.index &&
        !s.isWarmup &&
        s.completedAt === undefined &&
        s.weightKg === changed.weightKg,
    )
    .map((s) => s.id);
}

export function warmupIndex(lastWarmup: number | undefined, firstWork: number | undefined): number {
  if (lastWarmup === undefined) return firstWork === undefined ? 0 : firstWork - 1;
  return firstWork === undefined ? lastWarmup + 1 : (lastWarmup + firstWork) / 2;
}

  if (tracking === 'duration') return (set.durationSec ?? 0) > 0;
  if (tracking === 'bodyweight_reps') return (set.reps ?? 0) > 0;

}
```

```ts
/** SPEC §5.2 defaults; targetSec (duration exercises) is not in the spec. */
export const DEFAULT_TARGET = { sets: 3, repMin: 8, repMax: 12, targetSec: 30 };

/** SPEC §8.4: the day after the last completed one, wrapping; the first one otherwise. */
export function nextDay<T extends { id: string; order: number }>(
  days: T[],
  lastDayId: string | undefined,
): T | undefined {
  const sorted = [...days].sort((a, b) => a.order - b.order);
  const i = sorted.findIndex((d) => d.id === lastDayId);
  return sorted[i === -1 ? 0 : (i + 1) % sorted.length];
}

export function nextDayLabel(used: string[]): string {
  for (let i = 0; i < 26; i++) {
    const label = String.fromCharCode(65 + i);
    if (!used.includes(label)) return label;
  }
  return String(used.length + 1);
}

/** New order for every item after moving one up (-1) or down (1); empty at the edges. */
export function moveInList<T extends { id: string; order: number }>(
  items: T[],
  id: string,
  dir: -1 | 1,
): { id: string; order: number }[] {
  const list = [...items].sort((a, b) => a.order - b.order);
  const i = list.findIndex((x) => x.id === id);
  const j = i + dir;
  if (i === -1 || j < 0 || j >= list.length) return [];
  [list[i], list[j]] = [list[j], list[i]];
  return list.map((x, order) => ({ id: x.id, order }));
}
```

```ts
import Dexie from 'dexie';
import type { Exercise, SetLog } from '../types';
import { db, uid } from './db';

export type NewExercise = Pick<Exercise, 'name' | 'muscleGroup' | 'equipment' | 'trackingType' | 'notes'>;
export type ExercisePatch = Partial<
  Pick<
    Exercise,
    'name' | 'muscleGroup' | 'secondaryGroups' | 'equipment' | 'trackingType' | 'weightStepKg' | 'notes'
  >
>;

export interface ExerciseSession {
  sessionId: string;
  startedAt: number;
  sets: SetLog[];
}

export async function listExercises(): Promise<Exercise[]> {
  const all = await db.exercises.toArray();
  return all
    .filter((e) => e.archivedAt === undefined)
    .sort((a, b) => a.name.localeCompare(b.name, 'it'));
}

export const getExercise = (id: string): Promise<Exercise | undefined> => db.exercises.get(id);

export async function createExercise(input: NewExercise): Promise<string> {
  const id = uid();
  const now = Date.now();
  await db.exercises.add({
    ...input,
    id,
    name: input.name.trim(),
    secondaryGroups: [],
    isBuiltIn: false,
    createdAt: now,
    updatedAt: now,
  });
  return id;
}

export async function updateExercise(id: string, patch: ExercisePatch): Promise<void> {
  await db.exercises.update(id, { ...patch, updatedAt: Date.now() });
}

/** Used = referenced by a program day or by any session, also as the replaced exercise. */
export async function isExerciseInUse(id: string): Promise<boolean> {
  const counts = await Promise.all([
    db.dayExercises.where('exerciseId').equals(id).count(),
    db.sessionExercises.where('exerciseId').equals(id).count(),
    db.sessionExercises.filter((se) => se.replacedExerciseId === id).count(),
  ]);
  return counts.some((n) => n > 0);
}

/** SPEC §4.3: delete only if unused, otherwise archive so history keeps its name. */
export async function deleteOrArchiveExercise(id: string): Promise<'deleted' | 'archived'> {
  return db.transaction('rw', [db.exercises, db.dayExercises, db.sessionExercises], async () => {
    if (await isExerciseInUse(id)) {
      await db.exercises.update(id, { archivedAt: Date.now() });
      return 'archived';
    }
    await db.exercises.delete(id);
    return 'deleted';
  });
}

export async function restoreExercise(id: string): Promise<void> {
  await db.exercises.update(id, { archivedAt: undefined });
}

/** Completed sessions of one exercise, newest first, with their completed work sets. */
export async function exerciseHistory(
  exerciseId: string,
  limit = Number.POSITIVE_INFINITY,
): Promise<ExerciseSession[]> {
  // ponytail: loads every performed set of one exercise; fine for one person's history.
  // Upgrade path: walk the index with .each() and stop at `limit` sessions.
  const done = await db.setLogs
    .where('[exerciseId+completedAt]')
    .between([exerciseId, Dexie.minKey], [exerciseId, Dexie.maxKey])
    .reverse()
    .toArray();
  const sessionIds = [...new Set(done.map((s) => s.sessionId))]; // newest first
  const sessions = await db.sessions.bulkGet(sessionIds);
  const result: ExerciseSession[] = [];
  for (const session of sessions) {
    if (session?.status !== 'completed') continue;
    const sets = done
      .filter((s) => s.sessionId === session.id && !s.isWarmup)
      .sort((a, b) => a.index - b.index);
    if (sets.length === 0) continue;
    result.push({ sessionId: session.id, startedAt: session.startedAt, sets });
    if (result.length >= limit) break;
  }
  return result;
}
```

```ts
import { DEFAULT_TARGET, moveInList, nextDayLabel } from '../domain/program';
import type { Day, DayExercise, Exercise, Program } from '../types';
import { db, uid } from './db';
import { getSettings, setSetting } from './settings';

export interface DayItem {
  de: DayExercise;
  exercise: Exercise;
}

export interface ProgramRow {
  program: Program;
  dayCount: number;
}

export type DayExercisePatch = Partial<
  Pick<DayExercise, 'sets' | 'repMin' | 'repMax' | 'targetSec' | 'restSec' | 'notes' | 'supersetKey'>
>;

export async function listProgramRows(): Promise<ProgramRow[]> {
  const [programs, days] = await Promise.all([db.programs.toArray(), db.days.toArray()]);
  return programs
    .sort((a, b) => a.name.localeCompare(b.name, 'it'))
    .map((program) => ({ program, dayCount: days.filter((d) => d.programId === program.id).length }));
}

export const getProgram = (id: string): Promise<Program | undefined> => db.programs.get(id);

export async function createProgram(): Promise<string> {
  const id = uid();
  const now = Date.now();
  await db.transaction('rw', [db.programs, db.settings], async () => {
    await db.programs.add({ id, name: 'Nuovo programma', notes: '', createdAt: now, updatedAt: now });
    if (!(await getSettings()).activeProgramId) await setSetting('activeProgramId', id);
  });
  return id;
}

export async function updateProgram(
  id: string,
  patch: Partial<Pick<Program, 'name' | 'notes'>>,
): Promise<void> {
  await db.programs.update(id, { ...patch, updatedAt: Date.now() });
}

export async function duplicateProgram(id: string): Promise<string> {
  return db.transaction('rw', [db.programs, db.days, db.dayExercises], async () => {
    const program = await db.programs.get(id);
    if (!program) throw new Error(`Program ${id} not found`);
    const copyId = uid();
    const now = Date.now();
    await db.programs.add({
      id: copyId,
      name: `${program.name} (copia)`,
      notes: program.notes,
      createdAt: now,
      updatedAt: now,
    });
    for (const day of await db.days.where('programId').equals(id).toArray()) {
      const dayId = uid();
      await db.days.add({ ...day, id: dayId, programId: copyId });
      const items = await db.dayExercises.where('dayId').equals(day.id).toArray();
      await db.dayExercises.bulkAdd(items.map((de) => ({ ...de, id: uid(), dayId })));
    }
    return copyId;
  });
}

export const activateProgram = (id: string): Promise<void> => setSetting('activeProgramId', id);

export async function isProgramUsed(id: string): Promise<boolean> {
  return (await db.sessions.where('programId').equals(id).count()) > 0;
}

/** SPEC §4.3: delete only if no session references it; the active program is never archived. */
export async function deleteOrArchiveProgram(id: string): Promise<'deleted' | 'archived'> {
  return db.transaction(
    'rw',
    [db.programs, db.days, db.dayExercises, db.sessions, db.settings],
    async () => {
      const { activeProgramId } = await getSettings();
      if (await isProgramUsed(id)) {
        if (activeProgramId === id) throw new Error('The active program cannot be archived');
        await db.programs.update(id, { archivedAt: Date.now() });
        return 'archived';
      }
      const dayIds = await db.days.where('programId').equals(id).primaryKeys();
      await db.dayExercises.where('dayId').anyOf(dayIds).delete();
      await db.days.bulkDelete(dayIds);
      await db.programs.delete(id);
      if (activeProgramId === id) await setSetting('activeProgramId', null);
      return 'deleted';
    },
  );
}

export async function restoreProgram(id: string): Promise<void> {
  await db.programs.update(id, { archivedAt: undefined });
}

export const listDays = (programId: string): Promise<Day[]> =>
  db.days.where('programId').equals(programId).sortBy('order');

export const getDay = (id: string): Promise<Day | undefined> => db.days.get(id);

export async function addDay(programId: string): Promise<string> {
  return db.transaction('rw', db.days, async () => {
    const days = await listDays(programId);
    const id = uid();
    await db.days.add({
      id,
      programId,
      label: nextDayLabel(days.map((d) => d.label)),
      name: '',
      order: (days.at(-1)?.order ?? -1) + 1,
    });
    return id;
  });
}

export async function updateDay(id: string, patch: Partial<Pick<Day, 'label' | 'name'>>): Promise<void> {
  await db.days.update(id, patch);
}

/** Sessions keep their snapshot (dayLabel, dayName): nothing to update there. */
export async function deleteDay(id: string): Promise<void> {
  await db.transaction('rw', [db.days, db.dayExercises], async () => {
    await db.dayExercises.where('dayId').equals(id).delete();
    await db.days.delete(id);
  });
}

export async function moveDay(id: string, dir: -1 | 1): Promise<void> {
  await db.transaction('rw', db.days, async () => {
    const day = await db.days.get(id);
    if (!day) return;
    const changes = moveInList(await listDays(day.programId), id, dir);
    await db.days.bulkUpdate(changes.map(({ id: key, order }) => ({ key, changes: { order } })));
  });
}

export async function listDayItems(dayId: string): Promise<DayItem[]> {
  const items = await db.dayExercises.where('dayId').equals(dayId).sortBy('order');
  const exercises = await db.exercises.bulkGet(items.map((de) => de.exerciseId));
  return items.flatMap((de, i) => {
    const exercise = exercises[i];
    return exercise ? [{ de, exercise }] : [];
  });
}

export async function countDayExercises(programId: string): Promise<Record<string, number>> {
  const dayIds = await db.days.where('programId').equals(programId).primaryKeys();
  const items = await db.dayExercises.where('dayId').anyOf(dayIds).toArray();
  return Object.fromEntries(dayIds.map((id) => [id, items.filter((de) => de.dayId === id).length]));
}

export async function addDayExercise(dayId: string, exerciseId: string): Promise<string> {
  return db.transaction('rw', [db.dayExercises, db.exercises, db.settings], async () => {
    const existing = await db.dayExercises.where('dayId').equals(dayId).toArray();
    const exercise = await db.exercises.get(exerciseId);
    const { defaultRestSec } = await getSettings();
    const id = uid();
    await db.dayExercises.add({
      id,
      dayId,
      exerciseId,
      order: Math.max(-1, ...existing.map((de) => de.order)) + 1,
      sets: DEFAULT_TARGET.sets,
      repMin: DEFAULT_TARGET.repMin,
      repMax: DEFAULT_TARGET.repMax,
      ...(exercise?.trackingType === 'duration' ? { targetSec: DEFAULT_TARGET.targetSec } : {}),
      restSec: defaultRestSec,
      notes: '',
    });
    return id;
  });
}

export async function updateDayExercise(id: string, patch: DayExercisePatch): Promise<void> {
  await db.dayExercises.update(id, patch);
}

export async function removeDayExercise(id: string): Promise<void> {
  await db.dayExercises.delete(id);
}

export async function moveDayExercise(id: string, dir: -1 | 1): Promise<void> {
  await db.transaction('rw', db.dayExercises, async () => {
    const item = await db.dayExercises.get(id);
    if (!item) return;
    const siblings = await db.dayExercises.where('dayId').equals(item.dayId).toArray();
    const changes = moveInList(siblings, id, dir);
    await db.dayExercises.bulkUpdate(changes.map(({ id: key, order }) => ({ key, changes: { order } })));
  });
}
```

```tsx
import { X } from 'lucide-react';
import { type ReactNode, useEffect, useRef } from 'react';

interface Props {
  open: boolean;
  onClose: () => void;
  title: string;
  /** Tall sheet for long lists, e.g. the exercise picker. */
  full?: boolean;
  children: ReactNode;
}

/** Bottom sheet on the native <dialog>: focus trap, Esc and the top layer come for free. */
export function Sheet({ open, onClose, title, full = false, children }: Props) {
  const ref = useRef<HTMLDialogElement>(null);
  useEffect(() => {
    const dialog = ref.current;
    if (open && dialog && !dialog.open) dialog.showModal();
    if (!open && dialog?.open) dialog.close();
  }, [open]);
  return (
    // biome-ignore lint/a11y/useKeyWithClickEvents: closes on backdrop taps; Esc closes natively
    <dialog
      ref={ref}
      className={`sheet ${full ? 'h-[92dvh]' : ''}`}
      // Only a native close (Esc) reports back. When the parent closed us, its state already moved
      // on, possibly to another sheet: calling onClose again would close that one.
      onClose={() => {
        if (open) onClose();
      }}
      onClick={(e) => {
        if (e.target === e.currentTarget) onClose();
      }}
    >
      {open && (
        <div className="flex h-full flex-col pb-[env(safe-area-inset-bottom)]">
          <div className="flex min-h-14 items-center gap-2 pr-1 pl-4">
            <h2 className="flex-1 text-title font-semibold">{title}</h2>
            <button
              type="button"
              aria-label="Chiudi"
              className="flex size-11 items-center justify-center text-steel"
              onClick={onClose}
            >
              <X />
            </button>
          </div>
          <div className="flex-1 overflow-y-auto pb-4">{children}</div>
        </div>
      )}
    </dialog>
  );
}
```

```tsx
  min?: number;
  max?: number;
  /** Value set by the first ± tap when the field is empty. */
  fallback?: number;
  /** Weight: accepts "82,5" and "82.5". */
  decimal?: boolean;
  unit?: string;
  placeholder?: string;
  /** lg: 56pt targets for workout mode. */
  size?: 'md' | 'lg';
}

export function Stepper({
  label,
  value,
  onChange,
  step,
  min = 0,
  max = Number.POSITIVE_INFINITY,
  fallback = min,
  decimal = false,
  unit,
  placeholder,
  size = 'md',
}: Props) {
  const [draft, setDraft] = useState<string | null>(null);
  const clamp = (n: number) => Math.min(max, Math.max(min, Math.round(n * 100) / 100));
  const bump = (delta: number) => onChange(value === undefined ? fallback : clamp(value + delta));
  const commit = () => {
    if (draft === null) return;
    const text = draft.trim();
    const parsed = decimal ? parseWeight(text) : parseInteger(text);
    if (text === '') onChange(undefined);
    else if (parsed !== undefined) onChange(clamp(parsed));
    setDraft(null); // invalid text: back to the stored value
  };

  const height = size === 'lg' ? 'h-14' : 'h-11';
  const button = `flex ${height} w-14 shrink-0 items-center justify-center rounded-control bg-steel/15 active:opacity-60 disabled:opacity-30`;

  return (
    <div className="flex items-center gap-2">
      <button
        type="button"
        aria-label={`Diminuisci ${label.toLowerCase()}`}
        className={button}
        disabled={value !== undefined && value <= min}
        onClick={() => bump(-step)}
      >
        <Minus />
      </button>
      <label className={`flex ${height} min-w-0 flex-1 items-center`}>
        <span className="sr-only">{label}</span>
        <span className="flex w-full items-baseline gap-1">
          <input
            inputMode={decimal ? 'decimal' : 'numeric'}
            enterKeyHint="done"
            className={`num min-w-0 flex-1 bg-transparent outline-none placeholder:text-steel ${unit ? 'text-right' : 'text-center'} ${size === 'lg' ? 'text-value' : 'text-title'}`}
            value={draft ?? (value === undefined ? '' : formatNumber(value))}
            placeholder={placeholder}
            onFocus={(e) => {
              setDraft(e.currentTarget.value);
              e.currentTarget.select();
            }}
            onChange={(e) => setDraft(e.currentTarget.value)}
            onBlur={commit}
            onKeyDown={(e) => {
              if (e.key === 'Enter') e.currentTarget.blur();
            }}
          />
          {unit && <span className="flex-1 text-small text-steel">{unit}</span>}
        </span>
      </label>
      <button
        type="button"
        aria-label={`Aumenta ${label.toLowerCase()}`}
        className={button}
        disabled={value !== undefined && value >= max}
        onClick={() => bump(step)}
      >
        <Plus />
      </button>
    </div>
  );
}
```

```ts
import { nextDay } from '../domain/program';
import { prefill } from '../domain/workout';
import type { Day, Exercise, Program, Session, SessionExercise, SetLog } from '../types';
import { db, uid } from './db';
import { exerciseHistory } from './exercises';
import { type DayItem, listDayItems, listDays } from './programs';
import { getSettings } from './settings';

export interface TodayPlan {
  program: Program;
  /** Undefined when the program has no days yet. */
  day: Day | undefined;
  days: Day[];
  items: DayItem[];
}

export interface WorkoutItem {
  se: SessionExercise;
  exercise: Exercise;
  /** Live from the program day: notes are guidance, not history. */
  dayNote: string;
  sets: SetLog[];
}

export interface Workout {
  session: Session;
  items: WorkoutItem[];
}

export const getActiveSession = (): Promise<Session | undefined> =>
  db.sessions.where('status').equals('in_progress').first();

export async function getTodayPlan(): Promise<TodayPlan | null> {
  const { activeProgramId } = await getSettings();
  const program = activeProgramId ? await db.programs.get(activeProgramId) : undefined;
  if (!program) return null;
  const days = await listDays(program.id);
  const completed = await db.sessions
    .where('programId')
    .equals(program.id)
    .filter((s) => s.status === 'completed')
    .sortBy('startedAt');
  const day = nextDay(days, completed.at(-1)?.dayId);
  return { program, day, days, items: day ? await listDayItems(day.id) : [] };
}

export const countCompletedSince = (ts: number): Promise<number> =>
  db.sessions
    .where('startedAt')
    .aboveOrEqual(ts)
    .filter((s) => s.status === 'completed')
    .count();

/** Planned sets prefilled from the last completed session of the exercise (SPEC §8.3). */
export async function insertPlannedSets(
  se: Pick<SessionExercise, 'id' | 'sessionId' | 'exerciseId' | 'plannedSets'>,
): Promise<void> {
  const [last] = await exerciseHistory(se.exerciseId, 1);
  const values = prefill(last?.sets ?? [], se.plannedSets);
  await db.setLogs.bulkAdd(
    values.map((v, index) => ({
      ...v,
      id: uid(),
      sessionId: se.sessionId,
      sessionExerciseId: se.id,
      exerciseId: se.exerciseId,
      index,
      isWarmup: false,
    })),
  );
}

export async function insertSessionExercise(fields: Omit<SessionExercise, 'id' | 'status'>): Promise<string> {
  const id = uid();
  await db.sessionExercises.add({ ...fields, id, status: 'pending' });
  await insertPlannedSets({ ...fields, id });
  return id;
}

/** SPEC §6.1: one transaction; at most one session in progress (SPEC §4.3). */
export async function startSession(dayId: string): Promise<string> {
  return db.transaction(
    'rw',
    [db.sessions, db.sessionExercises, db.setLogs, db.days, db.dayExercises],
    async () => {
      if (await getActiveSession()) throw new Error('A workout is already in progress');
      const day = await db.days.get(dayId);
      if (!day) throw new Error(`Day ${dayId} not found`);
      const sessionId = uid();
      await db.sessions.add({
        id: sessionId,
        programId: day.programId,
        dayId,
        dayLabel: day.label,
        dayName: day.name,
        status: 'in_progress',
        startedAt: Date.now(),
        notes: '',
      });
      const planned = await db.dayExercises.where('dayId').equals(dayId).sortBy('order');
      for (const [order, de] of planned.entries()) {
        await insertSessionExercise({
          sessionId,
          exerciseId: de.exerciseId,
          order,
          plannedSets: de.sets,
          repMin: de.repMin,
          repMax: de.repMax,
          targetSec: de.targetSec,
          restSec: de.restSec,
          dayExerciseId: de.id,
          supersetKey: de.supersetKey,
        });
      }
      return sessionId;
    },
  );
}

export async function getWorkout(sessionId: string): Promise<Workout | undefined> {
  const session = await db.sessions.get(sessionId);
  if (!session) return undefined;
  const ses = await db.sessionExercises.where('sessionId').equals(sessionId).sortBy('order');
  const [exercises, dayExercises, sets] = await Promise.all([
    db.exercises.bulkGet(ses.map((se) => se.exerciseId)),
    db.dayExercises.bulkGet(ses.map((se) => se.dayExerciseId ?? '')),
    db.setLogs.where('sessionId').equals(sessionId).sortBy('index'),
  ]);
  const items = ses.flatMap((se, i) => {
    const exercise = exercises[i];
    if (!exercise) return [];
    const own = sets.filter((s) => s.sessionExerciseId === se.id);
    return [{ se, exercise, dayNote: dayExercises[i]?.notes ?? '', sets: own }];
  });
  return { session, items };
}
```

```ts
import type { SetValues } from '../domain/format';
import { propagateWeight, warmupIndex } from '../domain/workout';
import type { ActiveTimer, SessionExercise } from '../types';
import { db, uid } from './db';
import { getSettings, setSetting } from './settings';

export interface CompleteResult {
  exerciseDone: boolean;
  /** Absent: timer untouched (warmup, correction). null: timer cleared. Phase 2 mirrors it to push. */
  timer?: ActiveTimer | null;
}

/** done = has sets and all are completed; anything else is pending (a skipped one resumes). */
async function syncStatus(seId: string): Promise<boolean> {
  const sets = await db.setLogs.where('sessionExerciseId').equals(seId).toArray();
  const done = sets.length > 0 && sets.every((s) => s.completedAt !== undefined);
  await db.sessionExercises.update(seId, { status: done ? 'done' : 'pending' });
  return done;
}

async function restTimer(se: SessionExercise, exerciseName: string): Promise<ActiveTimer> {
  const work = (await db.setLogs.where('sessionExerciseId').equals(se.id).toArray()).filter(
    (s) => !s.isWarmup,
  );
  const done = work.filter((s) => s.completedAt !== undefined).length;
  const durationMs = se.restSec * 1000;
  return {
    sessionExerciseId: se.id,
    endAt: Date.now() + durationMs,
    durationMs,
    label: done > 0 ? `${exerciseName}, serie ${done} di ${work.length}` : exerciseName,
  };
}

/** SPEC §6.3: a weight change also updates later planned sets that had the same weight. */
export async function updateSet(setId: string, patch: SetValues): Promise<void> {
  await db.transaction('rw', db.setLogs, async () => {
    const set = await db.setLogs.get(setId);
    if (!set) return;
    const siblings = await db.setLogs.where('sessionExerciseId').equals(set.sessionExerciseId).toArray();
    const followers = 'weightKg' in patch ? propagateWeight(siblings, setId) : [];
    await db.setLogs.update(setId, patch);
    for (const id of followers) await db.setLogs.update(id, { weightKg: patch.weightKg });
  });
}

/** SPEC §6.3 and §7.1. Warmups and corrections never touch the timer. */
export async function completeSet(setId: string): Promise<CompleteResult> {
  return db.transaction(
    'rw',
    [db.setLogs, db.sessionExercises, db.exercises, db.settings],
    async () => {
      const set = await db.setLogs.get(setId);
      const se = set && (await db.sessionExercises.get(set.sessionExerciseId));
      const exercise = set && (await db.exercises.get(set.exerciseId));
      if (!set || !se || !exercise) throw new Error(`Set ${setId} not found`);
      const bodyweightDefault =
        exercise.trackingType === 'bodyweight_reps' && set.weightKg === undefined ? { weightKg: 0 } : {};
      await db.setLogs.update(setId, { completedAt: set.completedAt ?? Date.now(), ...bodyweightDefault });
      const exerciseDone = await syncStatus(se.id);
      if (set.isWarmup || set.completedAt !== undefined) return { exerciseDone };

      const { autoStartTimer } = await getSettings();
      const timer = autoStartTimer ? await restTimer(se, exercise.name) : null;
      await setSetting('activeTimer', timer); // a new confirmation replaces the running timer
      return { exerciseDone, timer };
    },
  );
}

export async function addSet(seId: string, isWarmup: boolean): Promise<void> {
  await db.transaction('rw', [db.setLogs, db.sessionExercises], async () => {
    const se = await db.sessionExercises.get(seId);
    if (!se) return;
    const sets = await db.setLogs.where('sessionExerciseId').equals(seId).sortBy('index');
    const work = sets.filter((s) => !s.isWarmup);
    const base = {
      id: uid(),
      sessionId: se.sessionId,
      sessionExerciseId: seId,
      exerciseId: se.exerciseId,
      isWarmup,
    };
    if (isWarmup) {
      const lastWarmup = sets.filter((s) => s.isWarmup).at(-1);
      await db.setLogs.add({ ...base, index: warmupIndex(lastWarmup?.index, work[0]?.index) });
    } else {
      const last = work.at(-1);
      await db.setLogs.add({
        ...base,
        index: (sets.at(-1)?.index ?? -1) + 1,
        weightKg: last?.weightKg,
        reps: last?.reps,
        durationSec: last?.durationSec,
      });
    }
    await syncStatus(seId);
  });
}

export async function deleteSet(setId: string): Promise<void> {
  await db.transaction('rw', [db.setLogs, db.sessionExercises], async () => {
    const set = await db.setLogs.get(setId);
    if (!set) return;
    await db.setLogs.delete(setId);
    await syncStatus(set.sessionExerciseId);
  });
}

export async function startTimer(seId: string): Promise<ActiveTimer | null> {
  return db.transaction(
    'rw',
    [db.setLogs, db.sessionExercises, db.exercises, db.settings],
    async () => {
      const se = await db.sessionExercises.get(seId);
      const exercise = se && (await db.exercises.get(se.exerciseId));
      if (!se || !exercise) return null;
      const timer = await restTimer(se, exercise.name);
      await setSetting('activeTimer', timer);
      return timer;
    },
  );
}

/** SPEC §7.1 "+15 s": endAt moves; durationMs too, so the line keeps its proportion. */
export async function extendTimer(ms: number): Promise<ActiveTimer | null> {
  return db.transaction('rw', db.settings, async () => {
    const { activeTimer } = await getSettings();
    if (!activeTimer) return null;
    const timer = {
      ...activeTimer,
      endAt: activeTimer.endAt + ms,
      durationMs: activeTimer.durationMs + ms,
    };
    await setSetting('activeTimer', timer);
    return timer;
  });
}

export const clearTimer = (): Promise<void> => setSetting('activeTimer', null);
```

```ts
import { useEffect, useState } from 'react';

/** Current time, refreshed every intervalMs and on every return to the foreground. */
export function useNow(intervalMs: number | null): number {
  const [now, setNow] = useState(Date.now);
  useEffect(() => {
    if (intervalMs === null) return;
    const tick = () => setNow(Date.now());
    tick();
    const id = setInterval(tick, intervalMs);
    document.addEventListener('visibilitychange', tick);
    return () => {
      clearInterval(id);
      document.removeEventListener('visibilitychange', tick);
    };
  }, [intervalMs]);
  return now;
}
```

```ts
import { useEffect } from 'react';

/** Keeps the screen on while mounted. iOS drops the lock when the page hides: re-acquire. */
export function useWakeLock(): void {
  useEffect(() => {
    let lock: WakeLockSentinel | null = null;
    let disposed = false;
    const acquire = async () => {
      if (document.visibilityState !== 'visible' || !('wakeLock' in navigator)) return;
      try {
        lock = await navigator.wakeLock.request('screen');
        if (disposed) await lock.release();
      } catch {
        // Not granted (low battery, older iOS): the screen may sleep, nothing else breaks.
      }
    };
    void acquire();
    document.addEventListener('visibilitychange', acquire);
    return () => {
      disposed = true;
      document.removeEventListener('visibilitychange', acquire);
      void lock?.release();
    };
  }, []);
}
```

Su iOS il Wake Lock funziona nelle app avviate dalla Home dalla versione 18.4. Sulle versioni precedenti la richiesta fallisce e il `catch` la ignora.

```ts
let context: AudioContext | null = null;

/** iOS plays Web Audio only after a user gesture: called on every pointerdown (cheap). */
export function unlockAudio(): void {
  context ??= new AudioContext();
  if (context.state !== 'running') void context.resume();
}

/** Two short beeps. No vibration: navigator.vibrate does not exist on iOS. */
export function beep(): void {
  if (context?.state !== 'running') return;
  const t = context.currentTime;
  for (const start of [0, 0.25]) {
```

```ts
export async function removeSessionExercise(seId: string): Promise<boolean> {
  return db.transaction('rw', [db.setLogs, db.sessionExercises], async () => {
    const sets = await db.setLogs.where('sessionExerciseId').equals(seId).toArray();
    if (sets.some((s) => s.completedAt !== undefined)) return false;
    await db.setLogs.bulkDelete(sets.map((s) => s.id));
    await db.sessionExercises.delete(seId);
    return true;
  });
}

export async function addSessionExercise(sessionId: string, exerciseId: string): Promise<string> {
  return db.transaction(
    'rw',
    [db.sessions, db.sessionExercises, db.setLogs, db.exercises, db.settings],
    async () => {
      const existing = await db.sessionExercises.where('sessionId').equals(sessionId).toArray();
      const exercise = await db.exercises.get(exerciseId);
      const { defaultRestSec } = await getSettings();
      return insertSessionExercise({
        sessionId,
        exerciseId,
        order: Math.max(-1, ...existing.map((se) => se.order)) + 1,
        plannedSets: DEFAULT_TARGET.sets,
        repMin: DEFAULT_TARGET.repMin,
        repMax: DEFAULT_TARGET.repMax,
        ...(exercise?.trackingType === 'duration' ? { targetSec: DEFAULT_TARGET.targetSec } : {}),
        restSec: defaultRestSec,
      });
    },
  );
}

/**
 * SPEC §6.5. Without completed work sets the exercise is swapped in place; otherwise it is
 * closed and the substitute takes the remaining sets right after it. The program never changes.
 */
export async function replaceExercise(seId: string, exerciseId: string): Promise<'replaced' | 'inserted'> {
  return db.transaction('rw', [db.sessions, db.sessionExercises, db.setLogs], async () => {
    const se = await db.sessionExercises.get(seId);
    if (!se) throw new Error(`Session exercise ${seId} not found`);
    const sets = await db.setLogs.where('sessionExerciseId').equals(seId).toArray();
    const doneWork = sets.filter((s) => s.completedAt !== undefined && !s.isWarmup).length;

    if (doneWork === 0) {
      await db.setLogs.bulkDelete(sets.map((s) => s.id));
      await db.sessionExercises.update(seId, {
        exerciseId,
        replacedExerciseId: se.replacedExerciseId ?? se.exerciseId,
        status: 'pending',
      });
      await insertPlannedSets({ ...se, exerciseId });
      return 'replaced';
    }

    await db.setLogs.bulkDelete(sets.filter((s) => s.completedAt === undefined).map((s) => s.id));
    await db.sessionExercises.update(seId, { status: 'done' });
    const later = await db.sessionExercises
      .where('sessionId')
      .equals(se.sessionId)
      .filter((x) => x.order > se.order)
      .toArray();
    for (const x of later) await db.sessionExercises.update(x.id, { order: x.order + 1 });
    await insertSessionExercise({
      sessionId: se.sessionId,
      exerciseId,
      order: se.order + 1,
      plannedSets: Math.max(1, se.plannedSets - doneWork),
      repMin: se.repMin,
      repMax: se.repMax,
      targetSec: se.targetSec,
      restSec: se.restSec,
      replacedExerciseId: se.exerciseId,
      supersetKey: se.supersetKey,
    });
    return 'inserted';
  });
}
```

```ts
/** SPEC §6.7; with atLastSet (stale session, §6.6) endedAt is the last completed set. */
export async function finishSession(sessionId: string, { atLastSet = false } = {}): Promise<void> {
  await db.transaction('rw', [db.sessions, db.setLogs, db.settings], async () => {
    const session = await db.sessions.get(sessionId);
    if (!session) return;
    const sets = await db.setLogs.where('sessionId').equals(sessionId).toArray();
    await db.setLogs.bulkDelete(sets.filter((s) => s.completedAt === undefined).map((s) => s.id));
    const lastSet = Math.max(session.startedAt, ...sets.map((s) => s.completedAt ?? 0));
    await db.sessions.update(sessionId, { status: 'completed', endedAt: atLastSet ? lastSet : Date.now() });
    await setSetting('activeTimer', null);
  });
}

/** Deletes a session with its exercises and sets. Also used by history (Phase 2). */
export async function discardSession(sessionId: string): Promise<void> {
  await db.transaction('rw', [db.sessions, db.sessionExercises, db.setLogs, db.settings], async () => {
    const session = await db.sessions.get(sessionId);
    await db.setLogs.where('sessionId').equals(sessionId).delete();
    await db.sessionExercises.where('sessionId').equals(sessionId).delete();
    await db.sessions.delete(sessionId);
    // Deleting an old session from history must not stop the rest timer of the current one.
    if (session?.status === 'in_progress') await setSetting('activeTimer', null);
  });
}

export async function setSessionNotes(sessionId: string, notes: string): Promise<void> {
  await db.sessions.update(sessionId, { notes });
```

```ts
import { DAY_MS, toDateKey } from './dates';

const REMINDER_AFTER_MS = 7 * DAY_MS;

/** SPEC §9: never backed up, or more than 7 days ago, and a workout completed since then. */
export function needsBackupReminder(
  lastBackupAt: number | null,
  lastWorkoutAt: number | undefined,
  now: number,
): boolean {
  if (lastWorkoutAt === undefined) return false;
  if (lastBackupAt === null) return true;
  return now - lastBackupAt > REMINDER_AFTER_MS && lastWorkoutAt > lastBackupAt;
}

export const backupFileName = (now: number): string => `palestra-backup-${toDateKey(now)}.json`;

export function backupPreview(backup: {
  data: { programs: unknown[]; sessions: { status: string; startedAt: number }[] };
}): { programs: number; sessions: number; lastSessionAt?: number } {
  const completed = backup.data.sessions.filter((s) => s.status === 'completed');
  return {
    programs: backup.data.programs.length,
    sessions: completed.length,
    lastSessionAt: completed.length ? Math.max(...completed.map((s) => s.startedAt)) : undefined,
  };
}
```

```ts
export async function exportBackup(now = new Date()): Promise<Backup> {
  const rows = await db.transaction('r', db.tables, () =>
    Promise.all(TABLES.map((name) => db.table(name).toArray())),
  );
  const data = Object.fromEntries(TABLES.map((name, i) => [name, rows[i]])) as Backup['data'];
  data.settings = data.settings.filter((s) => !DEVICE_SETTINGS.includes(s.key));
  return { app: 'gym-log', schemaVersion: BACKUP_VERSION, exportedAt: now.toISOString(), data };
}

/** Pure: validation never writes, so a rejected file leaves the data untouched. */
export function parseBackup(text: string): ParseResult {
  let json: unknown;
  try {
    json = JSON.parse(text);
  } catch {
    return invalid('il file non è in formato JSON');
  }
  const version = (json as { schemaVersion?: unknown } | null)?.schemaVersion;
  if (typeof version === 'number' && version > BACKUP_VERSION) {
    return { ok: false, error: "Backup creato da una versione più recente di Palestra. Aggiorna l'app e riprova." };
  }
  // ponytail: v1 is the only format. With Dexie v2, migrate older backups here before parsing.
  const result = backupSchema.safeParse(json);
  if (result.success) return { ok: true, backup: result.data };
  const [root, list, index] = result.error.issues[0]?.path ?? [];
  if (root === 'app') return invalid('il file non è stato esportato da Palestra');
  if (root === 'data' && typeof list === 'string' && list in LISTS) {
    const name = LISTS[list as TableName];
    return invalid(
      index === undefined ? `manca l'elenco ${name}` : `l'elenco ${name} contiene dati non riconosciuti`,
    );
  }
  return invalid('la struttura del file non è riconosciuta');
}

/** SPEC §9: replace everything in one transaction, no merge. */
export async function importBackup(backup: Backup): Promise<void> {
  await db.transaction('rw', db.tables, async () => {
    const pushEnabled = await db.settings.get('pushEnabled');
    await Promise.all(db.tables.map((table) => table.clear()));
    for (const name of TABLES) {
      const rows =
        name === 'settings'
          ? backup.data.settings.filter((s) => !DEVICE_SETTINGS.includes(s.key))
          : backup.data[name];
      await db.table(name).bulkAdd(rows);
    }
    if (pushEnabled) await db.settings.put(pushEnabled);
  });
}
```

```ts
/** SPEC §9: the share sheet (save to iCloud Drive) when available, else a download. */
export async function shareOrDownload(file: File): Promise<boolean> {
  if (navigator.canShare?.({ files: [file] })) {
    try {
      await navigator.share({ files: [file] });
      return true;
    } catch (error) {
      if ((error as Error).name === 'AbortError') return false; // the user cancelled
      // NotAllowedError: the tap's user activation expired while the backup was built.
      // Fall back to a download.
    }
  }
  const url = URL.createObjectURL(file);
  const link = Object.assign(document.createElement('a'), { href: url, download: file.name });
  link.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
  return true;
}
```
